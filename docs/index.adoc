= TinkerCat Documentation
:toc: left
:toclevels: 2
:icons: font

TinkerCat is a Kotlin Multiplatform implementation of the Apache TinkerPop in-memory graph database,
targeting JVM, JavaScript, and Native platforms from a single shared codebase.

This documentation is organised using the https://diataxis.fr[Diátaxis] framework.
Choose the section that matches what you are trying to do.

== Tutorials — learning by doing

New to TinkerCat?
Tutorials take you step-by-step through a complete task so you build real understanding as you work.

* xref:tutorials/getting-started.adoc[Getting Started] — install TinkerCat, build your first graph, and run a traversal.
* xref:tutorials/jvm.adoc[JVM Tutorial] — Gradle setup, concurrency, persistence, and Java interoperability.
* xref:tutorials/npm.adoc[npm / JavaScript Tutorial] — TypeScript types, the JS façade API, browser storage, and Node.js usage.
* xref:tutorials/native.adoc[Native Tutorial] — compile to a standalone binary or shared library, C FFI, and platform optimisations.
* xref:tutorials/python.adoc[Python Tutorial] — install the Python bindings, use the Pythonic API, and call the native shared library.
